# PDFeve - Nền tảng Xử lý & Biên tập PDF Đa năng 118-in-1

**PDFeve** là ứng dụng xử lý, chuyển đổi và biên tập tài liệu PDF toàn diện, hoạt động **100% Cục bộ & Ngoại tuyến (Offline)**, đảm bảo bảo mật tuyệt đối dữ liệu người dùng.

---

## ✨ Điểm nổi bật

- 🚀 **118 Công cụ PDF tích hợp:** Nối, tách, nén, chuyển đổi PDF sang Word chuẩn 100%, Excel, PowerPoint, ảnh, xoay trang, đóng dấu, đánh số trang, OCR nhận diện văn bản,...
- 🔒 **Bảo mật tuyệt đối:** Hoạt động offline 100% trên thiết bị của bạn, không gửi dữ liệu lên bất kỳ máy chủ bên ngoài nào.
- 📱 **Hỗ trợ Đa nền tảng:** macOS (Apple Silicon & Intel), Windows, và chia sẻ tức thì sang Điện thoại (iOS / Android) qua mã QR trên cùng mạng Wi-Fi.
- 🔄 **Hệ thống Auto-Update:** Tự động kiểm tra và nâng cấp phiên bản mượt mà qua GitHub Releases.

---

## 🛠 Hướng dẫn phát triển & Đóng gói

### 1. Cài đặt thư viện
```bash
npm install
```

### 2. Chạy thử nghiệm (Dev Mode)
```bash
npm start
```

### 3. Đóng gói ứng dụng
- **macOS:** `npm run build:mac`
- **Windows:** `npm run build:win`
